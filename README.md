# Electrical Harness Workbooks
**Project Documentation by Raisa Khatun | Electrical Engineering (EE), RKMGEC**

Example workbooks for designing, documenting, and constructing complex electrical wiring harnesses involving multiple connectors, electrical functions, and pin configurations.

Refer to the `Motorsport_Wiring_Harness_Construction.pdf` file for guidance on wire routing, connector assembly, and harness construction.

### General Guidelines

The workbook format is designed for practical electrical harness development, manufacturing, maintenance, and troubleshooting. It can be printed and compiled into a reference manual containing the following information:

1. Individual connector images with descriptive titles.
2. Unique connector identification codes for labeling.
3. Complete pin numbers and corresponding functions for every connector.
4. Wire colour identification and coding.
5. Wire endpoints and connection destinations.
6. Recommended American Wire Gauge (AWG) specifications.
7. Connector and terminal part numbers for component identification and procurement.

### Example Workbooks

The examples are divided into two workbooks:

1. **F98 Workbook** – A basic wiring harness documentation workbook for a 250CC sport bike engine, incorporating an ECU, gauges, and essential safety systems.

2. **F18 Workbook** – An advanced wiring harness documentation workbook for a 600CC sport bike engine, incorporating custom electronic systems, CAN bus communication, and servo motor controls.

### Project Background

These example workbooks were originally developed and used during Formula SAE (FSAE) vehicle design and development.

They provide a structured reference during electrical harness manufacturing, assembly, inspection, and troubleshooting. The documentation also makes it easier for future engineers and technicians to understand, maintain, and modify the electrical system with minimal additional software, setup, or prior knowledge.

### Available Formats

1. **Excel (.xlsx):** Original editable spreadsheet format, compatible with Microsoft Excel and other spreadsheet applications.
2. **HTML:** Browser-compatible format for viewing workbook information without requiring spreadsheet software.

### Important Notes for Customization

These workbooks can be adapted for specific vehicle or electrical system applications. Most manufacturers provide technical drawings and component specifications that can be used to update the documentation.

A few important sheets and their purposes are explained below:

1. **Parts Sheet:** Contains component labels, descriptions, and part numbers. It is useful for preparing purchase orders and maintaining an accurate component inventory.

2. **Basic Wire Info Sheet:** Provides reference information for selecting appropriate wire sizes based on SAE and MIL specifications.

3. **Wire Sizes Sheet:** Lists the wire sizes used for the particular application and provides references for different automotive electrical components.

4. **Relay & Fuse Diagram:** Illustrates the relay and fuse block arrangement used for electrical power distribution.

5. **Individual Component Sheets:** Each major electrical component is documented on a separate sheet with a unique identification label for easier reference and troubleshooting.
